# 🎮 명일방주: 엔드필드 (SKPORT) 백그라운드 자동 출석체크 가이드

이 프로젝트는 토큰 만료 문제 없이 **윈도우 PC(크롬)** 및 **안드로이드** 환경의 백그라운드에서 조용히 자동 출석체크를 진행하도록 제작되었습니다.

---

## 🖥️ 1. 윈도우 크롬 확장 프로그램 (추천)

사용자가 평소 사용하는 크롬 브라우저의 로그인 세션(쿠키)을 그대로 사용하므로 **토큰 만료나 별도의 토큰 추출 작업 없이 영구적**으로 작동합니다.

### 📌 설치 및 사용 방법
1. 크롬 주소창에 `chrome://extensions` 입력 후 접속합니다.
2. 우측 상단의 **[개발자 모드]** 스위치를 **켜기(ON)** 로 변경합니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
4. 해당 디렉터리의 `chrome-extension` 폴더를 선택합니다.
   - 경로: `d:\AntiGTemp\check End\chrome-extension`
5. 웹 브라우저에서 [SKPORT 엔드필드 공식 사이트](https://game.skport.com/endfield/sign-in)에 1회 로그인해 둡니다.

### ⚙️ 작동 방식 및 특징
- **크롬 시작 후 대기**: 크롬 브라우저를 실행하면 설정된 대기 시간(기본 10초) 후 백그라운드에서 조용히 출석 API를 호출합니다.
- **주기적 체크**: 크롬 실행 중에도 6시간 마다 자동으로 당일 출석 여부를 확인합니다.
- **결과 알림**: 출석 성공/실패 시 크롬 및 윈도우 시스템 알림으로 안내합니다. (설정에서 알림 끄기 가능)

---

## 📱 2. 안드로이드 백그라운드 앱 (WorkManager)

안드로이드 스마트폰이 켜져 있을 때 백그라운드 태스크(`WorkManager`)가 24시간 주기로 작동합니다.

### 📌 사용 방법
1. `android-app` 프로젝트를 Android Studio에서 열어 APK 빌드 후 설치하거나 빌드된 APK를 설치합니다.
2. 앱 실행 후 제공되는 내장 웹뷰에서 SKPORT 계정 로그인을 완료합니다.
3. 로그인이 완료되면 앱이 쿠키를 자동으로 감지 및 저장하며, 백그라운드 태스크가 자동 등록됩니다.
4. **"지금 수동 출석체크"** 버튼으로 언제든지 테스트할 수 있습니다.

---

## 🐍 3. 안드로이드 Termux / Tasker 스크립트 (가벼운 대안)

Termux 또는 Tasker / MacroDroid 앱을 사용하는 경우 파이썬 스크립트를 주기적으로 자동 실행할 수 있습니다.

```bash
# Termux 환경 준비
pkg update && pkg install python
pip install requests

# 실행 (토큰 전달)
python endfield_auto_checkin.py "YOUR_CRED_TOKEN"
```

---

## 🔍 검증 및 문제 해결 (Troubleshooting)

- **로그인 필요 메시지가 뜨는 경우**: SKPORT 웹사이트에 브라우저로 재접속하여 로그인이 유지되어 있는지 확인하세요.
- **수동 테스트**: 크롬 확장프로그램 팝업 UI에서 **"지금 즉시 출석체크"** 버튼을 눌러 동작을 확인할 수 있습니다.
